# גלי השרון – אפליקציית גלישה

תחזית גלישה לחופי הרצליה–קיסריה, מדורגת לפי הגלשן שלך. התחזית נמשכת ישירות מ-Open-Meteo בכל פתיחה.

## העלאה ל-GitHub Pages (פעם אחת)
1. github.com → New repository → שם: `surf` → Public → Create repository.
2. בעמוד הריפו: "uploading an existing file" → בחר את כל הקבצים מהתיקייה → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.
4. אחרי כדקה האפליקציה זמינה ב: https://afiksimon99.github.io/surf/
5. פתח את הכתובת ב-Safari → שיתוף → הוסף למסך הבית.

## קבצים
index.html, app.js (ממשק), engine.js (מנוע הדירוג), sw.js (עבודה בלי רשת), manifest.webmanifest ואייקונים.
